## 🔧 How I Learn

One thing I've learned from software engineering is that reading documentation is only part of learning technology.

I learn best by actually working with systems:

1. Build something.
2. Understand how the pieces communicate.
3. Break something intentionally or encounter a real problem.
4. Investigate the logs and symptoms.
5. Troubleshoot the problem.
6. Fix it.
7. Document what happened and why.

That's the approach I'm taking as I expand from software development into infrastructure, cloud, networking and data center technologies.
